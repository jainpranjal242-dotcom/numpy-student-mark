## Objective
Create a NumPy array containing student marks and calculate mean, median, maximum, minimum, and standard deviation.

## Dataset
[78, 85, 92, 67, 88, 74, 95, 81, 69, 90]

## Results
- Mean: 81.90
- Median: 83.00
- Maximum: 95
- Minimum: 67
- Standard Deviation: 9.2353
